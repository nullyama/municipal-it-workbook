# 自治体情シスの4択問題集

毎日5問ほど、応用情報レベルの基礎と自治体実務を結び付けるオリジナル教材。資料確認日は2026-11-03。試験範囲の完全網羅や、各自治体の内部規程への適合は保証しません。

学習ページ：https://municipal-it-daily-workbook.noid-u.chatgpt.site/

ログイン後の実端末間同期は未検証です。匿名の端末保存とJSON保存・復元は検証済み。認証・条件付き更新は自動テストで確認しています。

## 構成
- `web/questions.json`: 移植可能な全問題・解説・一次資料リンク・図のデータ
- `web/questions.js`: file://でも読める同内容のJavaScriptデータ
- `web/index.html`, `app.js`, `styles.css`: ライブラリ/CDN不要の画面
- `worker/api.js`: Sites認証済みIDに紐付く学習記録の保存API。R2にJSONを保存
- `scripts/build.mjs`: WebアセットをWorkerにまとめる依存ゼロのビルド
- `scripts/test.mjs`: データ・日付・形式検証・API認証・競合制御のテスト

## 使う
学習するだけなら公開された教材URLを開きます。インストール不要。匿名時は端末保存。ChatGPTでサインインすると同じアカウントの進捗を同期します。匿名/アカウント別のブラウザ保存領域は分離します。通信不能中は端末内に保存し、接続時に再同期します。開いていない端末にリアルタイムpushする方式ではありません。画面を再表示すると再取得します。端末時計は正しく設定してください。

`web/index.html`を直接開けば端末ローカル版としても使えます。この場合、クラウド同期は利用できません。ブラウザによってfile://の保存挙動は異なるため、JSONバックアップを利用してください。初回オフラインアクセスやサービスワーカーのオフラインキャッシュには対応していません。

## 開発
Node.js 22以降の標準ライブラリのみ。`npm test`、`npm run build`。依存パッケージのインストール不要。

公開リポジトリにはホスティング固有の識別子・認証情報・学習記録を含めません。`.openai/hosting.json` は意図的に除外しています。ホスティング側で新しいプロジェクトと `BUCKET` のR2保存領域を設定してください。設定なしでも `npm run build` でWorkerコードを生成できますが、そのまま配信・同期が設定されるわけではありません。

`oai-authenticated-user-id` はSitesが認証後に付与する信頼済みヘッダーとして扱っています。一般のホストでクライアントが任意指定したヘッダーを信頼してはいけません。他ホストへ移す際は、外部入力の同名ヘッダーを除去し、検証済みセッションから利用者IDをサーバー側で決定する認証層を実装してください。

GitHubへのソース保存だけでは履歴同期は成立しません。静的GitHub Pagesでは端末保存のみです。ソースと教材が公開されても個人の学習記録は公開しません。

## 保存と競合
本人の学習記録のみを保存。自由記述の入力・送信はありません。サインイン時は問題ID・選択した肢・正誤・旧自己評価・次回日・更新時刻を保存します。匿名APIは拒否。PUTは同一Originのみ、サイズ・形式を検証。R2の条件付き書込みで古いETagを409拒否し、クライアントが記録単位の更新時刻で統合します。同じ問題を同時に学ぶと新しい端末時刻の記録を採用します。監査・金融用途の厳密な順序保証ではありません。

## 復習
初回の正解は3日後、その後7/14/30日。不正解は翌日。実証済みの個別最適化モデルではなく簡単な復習支援です。休んでも罰則なし。未回答は記録しません。

## 出典と更新
各問に公式出典と確認日。第三者の問題の転載ではありません。制度・製品の変更時は一次資料を確認して問題を更新します。問題IDは保存履歴と対応するため既存IDを別問題に再利用しないでください。引用元の資料の著作権は権利者に帰属します。

## 4択版（v2）の記録
136問を4択に変更。正しいもの／誤っているものを選ぶ設問を明示し、全選択肢に解説を付けています。選択肢は回答回ごとに並べ替え、同じ回の移動・再読込みでは順序を保ちます。確定前は選び直せます。確定後の再採点・二重加算は行いません。

学習記録schema 1（以前の自己評価）をschema 2へ読み替えます。以前の自己評価と復習日は残りますが、4択の回答・正解数へ変換しません。4択で回答した後も旧自己評価をlegacyとして保持します。「直近の正答率」は各問の最新4択回答だけを分母にした割合で、累積の試行正答率ではありません。古い画面からのschema 1書込みはAPIが426で拒否するため、旧画面は再読込みしてください。

ソースと問題IDは維持します。学習日はJST。進行中セッションは端末のsessionStorageに保存し、再読込み後の開始ボタンで再開できます。日付が変わると新しい学習回を組みます。JSONバックアップは学習結果を含みますが、未確定の選択操作は含みません。
